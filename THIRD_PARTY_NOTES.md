# ML

## 1. Исходный набор данных

*`SBA Loan Data Case`* - исторический набор данных по кредитам Администрации малого бизнеса США (SBA). Используется в качестве основы для обучения модели, из оригинального набора данных было отобрано 8 признаков:

1. `NAICS` - код индустрии
2. `NewExist` - бизнес новый или уже существующий
3. `NoEmp` - число работников в кампании
4. `DisbursmentGross` - фактическая сумма выданного кредита в рублях
5. `Term` - срок, на который выдается кредит (в месяцах)
6. `RevLineCr` - линия кредита возобновляемая или нет
7. `MIS_Status` - кредит выплачен или предприниматель ушел в дефолт
8. `FranchiseCode` - код франшизы

*Лицензия набора данных* -  CC0 1.0 Universal (общедоступный датасет)

  

## 2. Сгенерированные данные
Всего было сгенерировано 18 признаков, генерация осуществлялась с учетом корреляции данных и их допустимых диапазонов. Дополнительно: к части фич добавляется шум в виде коэффициента `latent_risk_score`, который генерируется случайным образом через beta распределение
#### Данные, получаемые из *ЕГРЮЛ/ЕГРИП*
- `business_age_months` - возраст бизнеса, генерируется случайным образом; чем выше `latent_risk_score`, тем в среднем старше и стабильнее бизнес
- `okved_risk_level` - категория риска бизнеса, распределена случайным образом со следующими вероятностями: 1 (низкий) - 60%; 2(средний) - 30%; 3 (высокий) - 10%
- `authorized_capital` - уставной капитал (есть только у юр. лиц), генерируется случайным образом со следующими вероятностями: 10000 - 60%; 50000 - 30%; 100000 - 10%; 500000 - 10%
#### Данные от *ФНС*
- `revenue_last_year` - выручка за прошлый год связана с размером кредита, обычно в 1.5-5 раз больше суммы взятого кредита
 - `revenue_growth_rate` - темпы роста выручки (в процентах)
- `net_profit` - чистая прибыль кампании, зависит от выручки в прошлом году
- `hast_tax_appears` - наличие недоимок по налогам; чем ниже `latent_risk_score`, тем выше вероятность недоимки по налогам
- `has_blocked_accounts` - наличие блокировок банковских счетов
#### Информация от *БКИ*
- `bki_score` - оценка в Бюро Кредитных Историй
- `current_debt_load` - долговая нагрузка, обычно составляет от 10% до 80% годового дохода
- `max_delinquency_days` - максимальная просрочка в днях
- `active_credits_count` - количество актуальных кредитов (задолжностей)
#### Данные из *ФССП/Арбитражного суда*
- `fssp_debt_amount` - сумма задолженности
- `active_lawsuits_count` - количество судебных дел, рассчитывается через Пуассона
#### Данные от *пользователя*
* `loan_purpose` - цель кредита (пополнение оборотных средств/инвестиционные цели/рефинансирование бизнеса/исполнение контрактов/прочие рискованные цели)
* *`ownership_structure`* - структура владения бизнесом (одиночная кампания/взаимосвязанная МСБ группа)
* `business_scale` - масштаб бизнеса (микро/малый/средний)
  

## 3. Использованные библиотеки
- *`Pandas`* -  библиотека, предназначенная для работы со структурированными данными и их анализом 
- *`NumPy`* - библиотека, используемая для работы с большими многомерными массивами
- *`CatBoost`* - высокопроизводительная библиотека, предназначенная для обучения модели методом градиентного бустинга на решающих деревьях, а также сохранения и загрузки модели 
- *`Seaborn`* - библиотека, позволяющая наглядно визуализировать данные для их дальнейшего анализа

# Backend

## 1. Архитектура и назначение сервиса

Сервис бизнес-логики (`backend`) и сервис инференса (`backend-ml`) реализованы как асинхронные микросервисы на базе **Python 3.14** (`backend`) и **Python 3.12** (`backend-ml`), взаимодействующие по внутренней изолированной Docker-сети

*Лицензия базовых компонентов* - Open Source (MIT / BSD / Apache 2.0)

## 2. Использованные библиотеки
- *`FastAPI`* - асинхронный веб-фреймворк для построения REST API и автоматической генерации OpenAPI-спецификаций (MIT)
- *`Uvicorn`* - высокопроизводительный ASGI веб-сервер (BSD-3-Clause)
- *`SQLAlchemy (AsyncIO)`* - асинхронная ORM для работы с базой данных MariaDB (MIT)
- *`aiomysql`* - асинхронный драйвер подключения к MySQL/MariaDB (MIT)
- *`Alembic`* - инструмент управления миграциями базы данных (MIT)
- *`Pydantic` / `Pydantic Settings`* - валидация схем данных и типизированная загрузка конфигурации из `.env` (MIT)
- *`HTTPX`* - асинхронный HTTP-клиент для межсервисного взаимодействия (BSD-3-Clause)
- *`Cryptography`* - криптографические примитивы и защита данных (Apache 2.0 / BSD)
- *`Jinja2`* - шаблонизатор для генерации документов и отчетов (BSD-3-Clause)
- *`Scikit-learn` / `SHAP` / `Joblib`* - оценка метрик, интерпретация предсказаний модели и сериализация артефактов в `backend-ml` (BSD-3-Clause / MIT)
- *`uv`* - пакетный менеджер и сборщик виртуального окружения (MIT / Apache 2.0)
- *`Ruff` / `Pyrefly` / `Pytest`* - линтинг кода, статическая проверка типов и модульное тестирование (MIT)

# Frontend

## 1. Архитектура и контуры системы

Веб-платформа (`php-frontend`) построена на базе **PHP 8.4**, фреймворка **Laravel 12** и серверно-ориентированного UI-фреймворка **Filament 4**.

*Лицензия фреймворка и компонентов* - MIT License

## 2. Использованные библиотеки
- *`Laravel 12`* - основной PHP-фреймворк, обеспечивающий маршрутизацию, ORM (`Eloquent`), миграции, очереди и безопасность (MIT)
- *`Filament 4`* - полнофункциональный TALL-фреймворк (Tailwind, Alpine.js, Laravel, Livewire) для построения личного кабинета и админ-панели (MIT)
- *`Laravel Octane` + `Swoole`* - высокопроизводительный сервер приложений в production-режиме с удержанием состояния в памяти (MIT / Apache 2.0)
- *`Tailwind CSS 4` и `Vite 7`* - атомарная CSS-стилизация интерфейса и сборка фронтенд-ресурсов (MIT)
- *`Axios`* - HTTP-клиент для асинхронных запросов (MIT)
- *`Faker` / `PHPUnit` / `Laravel Pint`* - генерация тестовых данных, автотестирование и форматирование кода по стандарту PSR-12 (MIT)
